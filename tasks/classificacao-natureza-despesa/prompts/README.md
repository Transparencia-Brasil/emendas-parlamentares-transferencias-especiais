# README da pasta prompts

Esta pasta contém instruções e agentes utilizados para classificação e detalhamento de categorias de despesas no contexto do projeto TransfereGov. Os arquivos aqui presentes servem como base para automação e orientação dos processos de análise, classificação e detalhamento das naturezas de despesas, conforme normas e portarias vigentes.

## Estrutura dos arquivos

- **agente.md**: Define o agente responsável pela execução das tarefas de classificação e detalhamento.
- **instrucao-classificar-categorias.md**: Contém instruções para o processo de classificação das categorias de despesas.
- **instrucao-detalhar-categosias-classificadas.md**: Fornece orientações para detalhar as categorias já classificadas, garantindo maior precisão e conformidade normativa.

## Finalidade

Os arquivos desta pasta são utilizados como prompts para modelos de linguagem ou agentes automatizados, facilitando a padronização e a rastreabilidade dos processos de classificação e detalhamento das despesas públicas.

## Recomendações de uso

- Utilize os prompts conforme o fluxo de trabalho definido no projeto.
- Mantenha as instruções atualizadas conforme alterações nas normas ou processos internos.
- Consulte o arquivo `AGENTS.md` na raiz do projeto para mais informações sobre os agentes e fluxos de trabalho.
